This repository is an entry to the make.fun bounty "Sum up 23 November's world news in one image" (https://make.fun/bounty/news-image-20261123). The program main.ts copies entry.png — a one-image summary of the world news of Monday 23 November 2026, drawn by gen_image.py — into the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
